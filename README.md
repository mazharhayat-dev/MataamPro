# ASP.NET Core MVC Project

A modern, scalable web application built with ASP.NET Core 8 using MVC pattern and Clean Architecture.

### 🚀 Live Demo
> Coming soon on Azure - https://mazharhayatdev.azurewebsites.net

### 🛠️ Tech Stack
- **Framework:** ASP.NET Core 8.0
- **Language:** C#
- **Frontend:** Razor Views, Razor Pages, Bootstrap
- **Backend:** MVC, Services Layer
- **Database:** Entity Framework Core
- **Tools:** Visual Studio 2022, Git, GitHub, Azure

### 📁 Project Structure
- `Controllers/` - App controllers
- `Models/` - Data models
- `Views/` - Razor views
- `Pages/` - Razor Pages
- `Data/` - DbContext & EF Core config
- `Services/` - Business logic
- `wwwroot/` - Static files (CSS, JS, Images)
