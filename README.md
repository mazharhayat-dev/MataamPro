🍽️ MataamPro – Restaurant Management System

A modern web application built with ASP.NET Core 8 MVC, C#, Entity Framework Core, and a structured architecture.

Designed to simplify restaurant operations through an organized and user-friendly management system.

🚀 Live Demo

Coming Soon – Microsoft Azure

🛠️ Tech Stack

- Framework: ASP.NET Core 8.0 MVC
- Language: C#
- Frontend: Razor Views, Bootstrap, JavaScript
- Backend: MVC, Services Layer
- Database: SQL Server, Entity Framework Core
- Tools: Visual Studio 2022, Git, GitHub, Azure

✨ Current Features

- 📋 Menu Management
- 📂 Category Management
- 🛒 Order Management
- 📦 Stock Management

📁 Project Structure

- "Controllers/" – Application controllers
- "Models/" – Data models
- "Views/" – Razor views
- "Data/" – Database context and configuration
- "Services/" – Business logic
- "wwwroot/" – CSS, JavaScript, and images

⚙️ How to Run Locally

1. Clone the repository

git clone https://github.com/mazharhayat-dev/MataamPro.git

2. Open the project

Open the solution in Visual Studio 2022.

3. Configure Database

Update the SQL Server connection string in "appsettings.json".

4. Apply migrations

dotnet ef database update

5. Run the application

dotnet run
